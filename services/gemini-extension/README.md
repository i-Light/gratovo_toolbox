# Gemini extension

The browser extension that drives the signed-in Gemini web app for the Gemini bridge. It talks only to the local bridge daemon (`127.0.0.1`, with a per-launch token).

Empty for now. Step 6 ports it from `legacy/pipeline/gemini_extension/`, then moves it to TypeScript (see the [migration plan](../../docs/migration-plan.md#step-6-reach)).
