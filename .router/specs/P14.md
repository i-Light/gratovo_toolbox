## Write

1. **`docs/decisions/0013-pipeline.md`**: "The Python pipeline (step 3e-1)". Context, then the
   decisions, each with its reason:
   - one process per job, `<python> -I -u -m gratovo_pipeline`, with a bare environment
     (`SystemRoot`, `PATH`, `TEMP`, `TMP`; `-I` ignores `PYTHON*`, so the entry point sets UTF-8
     and `\n` itself);
   - the JSON-lines protocol version 1 (start/stop in; ready/run/keyword/channel/log/end out),
     zod as the source, the generated `protocol.schema.json`, main checking every line, three bad
     lines in a row end the job;
   - secrets only in the start message; the Data API key in the `X-Goog-Api-Key` header, never a
     URL, on an opener that follows no redirects; logs blanked of the job's secrets in main (file
     and page); the scraper logs a status and a path or an error's kind, never a URL;
   - the pipeline's own network rule (`net.check_url`: HTTPS, YouTube, Google's API, AWS gateway
     hosts);
   - `pipeline.db` owned by Python (schema version 1, WAL), main reads it read-only; example and
     live in separate folders;
   - the Data API over the standard library (no google-api-python-client);
   - stop: cuts the waits at once, keeps what was read (saved, stamped, announced), the keyword
     isn't marked done so a resume repeats it cheaply; main kills 30 s after a stop, 5 s at quit;
     stdin closing also stops;
   - failures by code: blocked, quota, network, no_youtube_key, crash (the page maps codes to its
     own words);
   - the example source (30 made-up AI channels, a 0.15 s pause per read so a run can be watched);
   - the queue in `find.json` beside `pipeline.db` instead of `local_settings` (and why);
   - proxies, AWS gateways and parallel search kept (the owner's answer of 2026-10-21), their URLs
     from the secret store `pipeline.proxies` and `pipeline.gateways`;
   - what waits for 3e-2 (R2 sharing) and 3e-3 (the rest), from PLAN.md's outlines.
   Add it to the list in `docs/decisions/README.md` if there is one.
2. **`docs/architecture.md`**: where it describes the pipeline, add a short paragraph on how a
   search runs now (main's supervisor and find service, the protocol, the pipeline's network rule)

3. **`SECURITY.md`**: in the right place, the pipeline's rules in a few lines: secrets only on

4. **`services/pipeline/README.md`**: how the package is laid out (the modules under
